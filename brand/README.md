# Principia Artificialis seal

| File | Use |
|---|---|
| `pa_seal.svg` | Full seal with the word VERITAS (64 px and larger) |
| `pa_seal_mark.svg` | Seal without text: site header and favicon |
| `pa_seal_512.png`, `apple-touch-icon.png` (180 px), `favicon-32.png` | Raster copies rendered from the SVGs |

A Π, for *Principia*, inside a hexagonal seal. Chosen by the owner on 2026-10-22 from three original concepts
(fracture, geodesic, seal). It replaces the earlier circled Π on the homepage and dashboard. See
[BRAND_POLICY.md](../BRAND_POLICY.md) for how the name and mark may be used.

The PNGs were rendered from the SVGs with headless Chromium. The full seal's text uses the system serif font
(Georgia where available), so its lettering can differ slightly between machines. The mark has no text.

Provenance: Claude (Anthropic, Opus 5.5) designed and drew the concepts in SVG → human validation: not performed →
human editing/curation: Chad Holland chose the seal (2026-10-22) → human responsibility: Chad Holland.
Review level: outcome review (choice between rendered concepts). Licensed with the repository (MIT).
