The Liar's Note

Get a wrong number past the number checker. Principia Artificialis has one rule it treats as law: every number in a research note must match what its code printed. check_numbers.py enforces it. Write a note whose number the output does not support, and get the checker to report it FOUND. Correct rounding and coincidences (another printed number that rounds to yours) are not wins. No defect is asserted. Rules, board and how to submit.

Loading Python in your browser (Pyodide). The first load takes a few seconds.


  
Everything runs in your browser: the unmodified check_numbers.py and judge.py from the
  repository, in Python compiled to WebAssembly. Nothing you type is sent anywhere or run as code. A win counts once a maintainer
  reproduces it from a clone with ordinary Python.
