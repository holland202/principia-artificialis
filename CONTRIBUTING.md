# Contributing to Principia Artificialis

Thank you for your interest in contributing!

## Ways to Contribute

- Submit a Research Note
- Propose or work on an Experiment
- Provide mathematical proofs or counterexamples
- Review and critique existing notes
- Add references or literature reviews
- Implement simulations
- Improve documentation

## Pull Requests

PRs are welcome for code, documents, etc. Follow the structure in research_notes/.

## Issues

Use Issues for specific research problems.

## Discussions

Use GitHub Discussions for broader conversations.

## Research Gateway pilot — guided first contribution

Start at [JOIN_RESEARCH.md](JOIN_RESEARCH.md), choose one [bounded research opportunity](RESEARCH_OPPORTUNITIES.md), and submit an evidence-pinned issue using the new *Research evidence or counterexample* template. Source review without running code is welcome. Negative findings should remain visible. Anyone may participate through Issues and forked PRs without direct repository write access.

The volunteer [review playbook](REVIEW_PLAYBOOK.md) is nonbinding guidance, not approval of experiments or science claims. [METHOD.md](METHOD.md), [WORKFLOW.md](WORKFLOW.md), [CONTROLS.md](CONTROLS.md), and [DISCUSSION_NORMS.md](DISCUSSION_NORMS.md) still govern. Formal research freezes, experimental authorization, merges and publication require explicit authorized maintainer decisions. Do not execute reserved research seeds or alter frozen/historical results.
