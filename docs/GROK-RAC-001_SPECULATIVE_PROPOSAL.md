## 1. Critical technical correction (causal objection — retained and strengthened)

**Objection (owner):**  
> Your injection time is randomly selected independently of the preceding trajectory. If the system has no advance information about that injection, a causal detector cannot reliably predict the immediately preceding step.

**Response:** The original exogenous-random-injection design is **DEFECTIVE** for any online causal claim and is withdrawn. It is preserved only in Appendix A for audit (M12).

**Corrected causal structure (v2):**

- An *observable instability precursor* is generated by a slow, deterministic drift of the local spectral radius of the residual map. The drift is a function of residual history only.
- When the precursor scalar first exceeds a fixed threshold θ, an irreversible map change is applied at the *next* discrete step.
- The lag-1 residual autocorrelation is hypothesized to detect the *onset of this observable instability*, not an unpredictable future event.
- All detector decisions use only information available at or before the onset step. No post-injection residual enters the decision that is claimed to be predictive.

**Temporal indexing (exact):**
- `t = 0,1,…,T` indexes residual vectors *after* each application of the map.
- `t_onset` ≜ first `t` at which the registered precursor scalar `s_t ≥ θ`.
- Irreversible injection occurs at step `t_inj = t_onset + 1`.
- Detector output `hat_t` is required to satisfy `hat_t ≤ t_onset` for any claim of “early warning”; post-injection information is forbidden for the predictive decision.

**Irreversibility condition (exact):**  
After `t_inj` the local map is replaced by a permanently altered operator `A_post` whose spectral radius is fixed above the pre-onset value and whose dominant eigenspace is rotated by a fixed angle φ > 0 relative to the pre-onset dominant direction. Under the registered noise level the trajectory cannot return to the pre-injection attractor; recovery would require an explicit restorative intervention that is absent from the generator.

## 2. Fully specified generator (SyntheticResidualMap-Causal v2)

Stand-in name: **SyntheticResidualMap-Causal** (NumPy-only; to be implemented only after registration authorization).

**State:** residual vector `r_t ∈ ℝ^d`.

**Pre-onset dynamics:**
```
r_{t+1} = A_t r_t + ε_t,   ε_t ∼ 𝒩(0, σ² I)
```
where `A_t = ρ_t · Q_t`, `Q_t` is a fixed orthogonal matrix (or a slowly rotating orthogonal matrix), and the scalar gain `ρ_t` evolves as

```
ρ_{t+1} = ρ_t + α · g(‖r_t‖²) ,   ρ_0 = ρ_init < 1
```
with `α > 0` small and `g` a non-decreasing function (default: identity clipped to a registered bound). Thus spectral radius drifts upward solely as a function of residual energy history.

**Precursor scalar (observable, causal):**
```
s_t ≜ ρ_t          # or a trailing-window estimate of the dominant singular value of the recent update operators
```
`t_onset` is the first `t` with `s_t ≥ θ`. Injection occurs at `t_inj = t_onset + 1`.

**Post-injection dynamics:**
```
A_post = ρ_post · R_φ Q ,   ρ_post > θ ,   φ = π/6 (fixed)
r_{t+1} = A_post r_t + ε_t   for all t ≥ t_inj
```
`R_φ` is a fixed rotation in a 2-plane. This change is permanent for the remainder of the trajectory.

**Constants (proposed values for any future registration; still free until frozen under W2):**

| Symbol | Proposed value | Role |
|--------|----------------|------|
| `d`    | 32             | residual dimension |
| `T`    | 40             | trajectory length |
| `N`    | 200            | number of independent trials |
| `ρ_init` | 0.85         | initial spectral radius |
| `α`    | 0.008          | drift rate |
| `θ`    | 0.97           | instability threshold |
| `ρ_post` | 1.05         | post-injection radius |
| `σ`    | 0.05           | noise std |
| `φ`    | π/6            | irreversible rotation |
| `w`    | 8              | trailing window for optional PC reduction |
| `τ`    | 0.65           | autocorrelation detection threshold (inclusive) |

All values above remain **unfrozen**. Any formal registration must lock them before the first run.

## 3. Autocorrelation definition (exact)

Two admissible reductions (both causal):

**A. Full-vector lag-1 Pearson autocorrelation**
```
ρ_t =  [(r_t − μ)ᵀ (r_{t+1} − μ)] / (‖r_t − μ‖ ‖r_{t+1} − μ‖)
```
where `μ` is the mean of the trailing window of length `w` ending at `t` (or the global mean of the trajectory prefix up to `t` if a cumulative definition is preferred). The window never includes residuals after `t`.

**B. Leading-PC time-series autocorrelation**  
Compute the leading principal component of the trailing window of residuals ending at `t`, project the same window onto that component to obtain a scalar series `c_s` (`s ≤ t`), then compute ordinary lag-1 autocorrelation of that scalar series.

The primary claim uses definition A; definition B is a robustness variant. Both are strictly causal: no future residual enters the computation of `ρ_t`.

Detection rule: the first `t` at which `ρ_t < τ` (inclusive) is reported as `hat_t`. If no such `t` occurs before `T`, the detector returns “no detection”.

## 4. Competing hypotheses and baselines (M14)

**H0 / simplest rival (residual-norm growth):**  
`‖r_{t+1}‖ / ‖r_t‖ > γ` (γ chosen so that the baseline has the same lead-time budget as the autocorrelation detector). Claim: this alone is sufficient; any apparent advantage of autocorrelation is an artefact.

**H1 / critical-slowing-down (CSD) rival:**  
Near a bifurcation the dominant eigenvalue approaches the unit circle from below, producing a characteristic rise in lag-1 autocorrelation *and* a rise in variance. The CSD hypothesis asserts that a simple variance (or residual-energy) threshold already captures the same information; autocorrelation adds nothing once variance is monitored.  
Consequently a variance-based baseline is included:
```
v_t = (1/w) Σ_{k=0}^{w−1} ‖r_{t−k} − μ‖²
```
Detection when `v_t > v_thresh`.

**H2 / direct precursor monitor (strongest causal baseline):**  
Because the instability precursor `s_t = ρ_t` is *known to the experimenter* and is the direct cause of injection, a detector that simply thresholds `s_t` itself is an oracle baseline. Any useful early-warning statistic must be compared against this oracle.  
The scientific claim is therefore *not* that autocorrelation beats the oracle, but that autocorrelation, which does *not* receive `ρ_t` as an explicit input, still recovers the onset with useful precision from the residual trajectory alone.  
If autocorrelation cannot outperform (or at least match the timing of) a residual-norm or variance baseline while remaining competitive with the oracle on a substantial fraction of trials, the hypothesis is weakened.

**Baseline set for the experiment:**
1. Residual-norm growth (H0).
2. Residual variance / energy (CSD rival).
3. Direct precursor threshold on `s_t` (oracle).
4. Lag-1 residual autocorrelation (proposed statistic).

All four are evaluated on identical trajectories under identical lead-time constraints.

## 5. Numbered candidate predictions (NOT REGISTERED)

These remain candidates only. They are not frozen under W2.

**P1 (candidate).** On `N = 200` independent trials generated by SyntheticResidualMap-Causal v2, the first step at which the full-vector lag-1 autocorrelation falls below `τ = 0.65` occurs at or immediately after `t_onset` (i.e., `|hat_t − t_onset| ≤ 1`) on at least 70 % of trials. Exact binomial test against null success probability 0.5, two-sided, α = 0.05.

**P2 (candidate).** Mean absolute error `|hat_t − t_onset|` of the autocorrelation detector is strictly smaller than that of both the residual-norm baseline and the residual-variance baseline (paired comparisons on the same trials).

**P3 (anti-vacuity, candidate).** When `θ` is set so high that `s_t` never reaches it (no injection ever occurs), the autocorrelation statistic remains ≥ 0.65 for all `t` on at least 95 % of trials.

**P4 (robustness, candidate).** Under a 2× increase in noise variance `σ²`, P1 still holds.

**P5 (oracle comparison, candidate).** The fraction of trials on which autocorrelation recovers `|hat_t − t_onset| ≤ 1` is at least 60 % of the fraction achieved by the direct-precursor oracle on the same trials.

Falsification of the central scientific claim occurs if P1 or P2 fails under the (still-to-be-frozen) constants.

## 6. Statistical controls and sabotage behaviour

**C-NOISE.** Before any threshold is interpreted, the same input trajectory seed is run ≥ 3 times; the observed spread of `ρ_t` is recorded. Any registered bound smaller than that spread is declared unresolvable at that `N`.

**C-STAT.** All hypothesis tests are fixed-horizon (exact binomial for P1; paired differences for P2). No sequential peeking. e-process machinery is available but not required for the deterministic-map core; it would be used only if a later empirical stage introduces sampling over real model residuals.

**Sabotage / anti-vacuity (M3, C-BUILD):**
- Force `ρ_t ≡ 1` for every `t` → instrument must return GATE: FAIL and exit 1.
- Zero-variance trajectory (all residuals identical) → instrument must return a defined UNDEFINED / SKIP verdict, never a false positive detection.
- Missing or malformed residual sequence → DENY / UNVERIFIED, never a silent skip that is later treated as success.

## 9. Limitations and confounders

- Synthetic linear / mildly non-normal map may not capture real transformer residual dynamics (non-normality, attention-induced rank collapse, discrete token boundaries).  
- `τ = 0.65` is arbitrary (chosen for falsifiability).  
- The precursor `s_t = ρ_t` is an internal generator variable; a real system would need an operational definition of the analogous observable.  
- Window length `w` and dimension `d` interact with noise level; sensitivity is left as a door.  
- The original exogenous-injection design remains on the permanent record as DEFECTIVE.
