# Starter research opportunities — public pilot

**All starter tasks are optional examples, not an approved-subject list.** Researchers may propose an original topic, develop independent exploratory work in a fork, and open an issue or PR immediately without seeking permission or an assignment. These bounded, unassigned leads are **not** assertions that any defect still exists or authorizations for official PA scientific execution. Check current sources and [open starter issues](https://github.com/holland202/principia-artificialis/issues?q=is%3Aissue+is%3Aopen+PA-ENTRY) if choosing one of these examples.

**How these relate to the [challenge menu](challenges/entry/README.md):** the menu's PA-C1–PA-C6 are open challenge *categories*; each PA-ENTRY item below is one pre-scoped *instance* (PA-ENTRY-01 is a PA-C1-style task, PA-ENTRY-02 a PA-C2-style task). Either route is valid.

A good starter task has a precise source, one question, a concrete evidence deliverable and a stopping point. Estimated effort is a planning aid, not observed performance.

| ID | Task | Approximate effort | Smallest acceptable submission |
|---|---|---|---|
| PA-ENTRY-01 | Classify one historical number mismatch | 30–90 minutes | Source-pinned issue with one number, classification and reason |
| PA-ENTRY-02 | Trace one potentially vacuous verification gate | 30–90 minutes | Proposed admissible counterexample and whether it was tested |
| PA-ENTRY-03 | Check one paper attribution in exploratory notes | 30–90 minutes | Exact cited passage, original reference and bounded correction |
| PA-ENTRY-04 | Challenge one assumption in the Circularity Test | 1–3 hours | One precise mathematical critique or counterexample |

## PA-ENTRY-01 — one number, not a census

**Sources:** [historical NUMBER_CHECK audit](results/NUMBER_CHECK.md), its linked research note and reference script, [dated README audit](README.md).

**Question:** Does one historically “NOT FOUND” number remain unexplained at the commit you inspect, or is it a parameter, historical value, derived quantity, or false mismatch?

**Deliverable:** One pinned line, number, classification, and evidence. If a permitted existing reference script is run, include exact command, stdout/stderr, environment and exit. Otherwise mark SOURCE REVIEW ONLY.

**Stop:** One number. Do not rewrite historical counts, regenerate the index or edit research claims.

## PA-ENTRY-02 — anti-vacuity source trace

**Sources:** [verification-that-cannot-fail note](research_notes/note052_verification_that_cannot_fail.md), one specific checker under [scripts](scripts/).

**Question:** Can an admissible failure actually reach a negative verdict? What minimal mutated input would demonstrate it?

**Deliverable:** Source/commit-pinned proposed sabotage, expected outcome, and disclosure of whether executed. Check for existing tests before alleging a new defect.

**Stop:** One gate. A source hypothesis is not a reproduced failure.

## PA-ENTRY-03 — attribution review

**Sources:** [exploratory research notes](research_notes/) 068–070 referenced in [Issue #26](https://github.com/holland202/principia-artificialis/issues/26).

**Question:** Does one cited original paper support the precise attribution, including its date, scope and limits?

**Deliverable:** Exact note/line, original paper link, bibliographic identity, specific suggested correction or unresolved question.

**Stop:** One citation. Do not promote exploratory architecture notes to validated research.

## PA-ENTRY-04 — mathematical counterexample

**Sources:** [Circularity Test note](research_notes/note044_circularity_test.md) and its cited reference script.

**Question:** Which precise assumption, definition or intermediate step could be false? Can you construct a discriminating counterexample?

**Deliverable:** One short derivation or counterexample with assumptions, source location, and limits. An unexecuted proposed test must be labeled NOT RUN.

**Stop:** One claim, without rewriting the original finding.
